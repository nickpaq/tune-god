Methods, versions & limitations

Corrected TuneGod uses separately normalized bass and full-spectrum onset evidence for grid fitting, includes the first analysis frame, and considers a credible beat at the audio boundary when choosing bar 1. Original and corrected TuneGod also run the existing transient-template drift correction. A very loud offbeat sound can still defeat detection. Music Tempo uses its native BeatRoot-style tracker. Web Audio Beat Detector uses its native 240 Hz low-pass, peak-interval voting, default 90–180 BPM search range and rounded BPM output.

No library can promise a perfect musical downbeat for every recording. Listen to the accented click, place a manual downbeat, and compare later parts for tempo drift. One marker fixes phase; rerunning from that point can improve the tempo estimate by excluding an intro. Assisted grids extend backwards through the intro too.

Music Tempo and Web Audio Beat Detector are vendored under their MIT licenses. This standalone test adds common file handling, playback and anchoring; manual markers are not native features of those libraries.
